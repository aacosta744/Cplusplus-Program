## Corner Grocer Item Tracking Program

### 1. Project Summary
###    The Corner Grocer Item-Tracking Program was created to help a small grocery store keep track of how often different items were purchased. The program reads a text file containing a list of grocery ###    items and counts how many times each item appears. It uses a GroceryTracker class and a C++ map to store each item and its purchase frequency. The program allows the user to search for an 
###    individual item, display all item frequencies, and display a histogram showing the frequency of each item. The program also creates a backup file containing the item frequencies.

### 2. What I Did Well
###    I think I did well with organizing the program into separate files and using a class to manage the grocery item data. Using a map allowed me to store each grocery item with its frequency and made ###    it easier to search for items and display the information in alphabetical order. I also made sure the program included the required menu options and that the different functions worked together. ###    Another area I did well in was debugging the program when I had problems with the input file and making sure the program was able to read the grocery data correctly.

### 3. Improvements
###    One area where I could improve my code is adding more input validation and error handling. For example, the program could handle situations where the input file is missing, cannot be opened, or ###    contains unexpected information. I could also improve the user input validation so that the program does not have problems if the user enters something other than what the menu expects. These      ###    changes would make the program more reliable and easier to use. As I continue learning C++, I could also look for ways to make some of the functions more efficient and reduce repeated code.

### 4. Challenges and How I Overcame Them
###    The most challenging parts of this project were learning how the map worked, working with files, and understanding how the different C++ files worked together. I also had some difficulty getting ###    the program to find and read the input file correctly. I overcame these problems by testing the program, checking my code carefully, using the debugger in Visual Studio, and reviewing the course ###    material. I also used resources such as ZyBooks and C++ documentation when I needed additional explanations. These resources will continue to be part of my support network as I work on more        ###    programming projects.

### 5. Transferable Skills
###    Several skills from this project will transfer to future programming courses and projects. I gained more experience with C++, classes, functions, maps, file input and output, debugging, and       ###    organizing a program into multiple files. I also improved my problem-solving skills because I had to figure out why parts of my program were not working and then test different solutions. Learning ###    how to use GitHub for this project is also an important skill because I can use it to store and showcase future projects and eventually use it as part of my professional portfolio.

### 6. Maintainability, Readability, and Adaptability
###    I made the program more maintainable and readable by separating the GroceryTracker class into a header file and implementation file and keeping the main program in main.cpp. I used descriptive     ###    names for variables and functions so that it was easier to understand what different parts of the program were doing. The class structure also makes the program easier to modify because changes to ###    the grocery tracking functionality can be made within the class without having to rewrite the entire program. Using a map also makes the program adaptable because additional grocery items can be   ###    added to the input file without needing to change the program's basic structure.
